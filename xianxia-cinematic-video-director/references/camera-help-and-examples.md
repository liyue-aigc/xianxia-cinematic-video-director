# 运镜帮助与案例

## 30 秒快速入门

不会写术语时，只需提供四件事：

```text
场景：在哪里？
主体：谁或什么是画面中心？
变化：主体从开始到结束做了什么？
感觉：希望观众感到宁静、压迫、速度、震撼、亲近还是失衡？
```

可复制公式：

```text
从<稳定起始构图>开始，镜头为了<叙事目的>，以<速度曲线>沿<方向/路径>运动<幅度>；主体<动作>；最后落在<稳定结束构图>，揭示<新信息>。禁止<冲突运动/常见故障>。
```

不知道选什么时，给用户 2–3 条路线并推荐一条；路线必须改变观感，而不只是替换术语。

## 按目的选运镜

| 叙事目的 | 推荐手法 | 速度建议 | 常见误用 |
|---|---|---|---|
| 揭示宏大空间 | 遮挡横移、拉远、升降、航拍抬升 | 中缓 -> 减速 -> 停 | 全程慢推却没有新信息 |
| 跟随行进 | 后跟、前领、侧跟、长焦跟随、静机位掠过 | 匀速或随主体加速 | 镜头和人物都乱变速 |
| 追逐/逃亡 | 低位追拍、POV穿越、航拍俯冲、甩镜转场 | 中快、加速、急停 | 长时间高速摇晃导致不可读 |
| 打斗冲击 | 静机位入画、短弧线跟随、快速推进、控制震动 | 等待 -> 爆发 -> 停 | 把整套招式塞进一个镜头 |
| 对峙/威压 | 锁定机位、极缓侧移、长焦压缩、低机位抬升 | 静止或极缓 | 为“高级”不停环绕 |
| 亲近/情绪 | 轻推、前领后退、越肩、焦点转移 | 缓慢但要有落点 | 所有情绪都用同一慢推 |
| 疏离/失落 | 拉远、人物离镜、静态远景、升高俯视 | 减速或静止 | 运动方向与情绪相反却无意图 |
| 魔法觉醒/反转 | 局部环绕、抬升、焦点转移、克制变焦 | 静 -> 加速 -> 急停 | 360°环绕加翻滚造成建筑变形 |
| 眩晕/认知冲击 | dolly zoom、短滚转、焦点跳转 | 短促，随后恢复稳定 | 长时间滚转破坏方向感 |

## 案例 1：宏大揭示——遮挡横移 + 升起落稳

适用：仙门、天宫、巨像、云海城市第一次出现。

```text
6秒，21:9，24mm广角。起始画面由近景巨型松干遮住右侧空间，成年剑修只占画面高度4%。运镜目的：通过逐层揭示建立尺度。0–3秒镜头以中缓速度向右横移约3米，利用松干产生强视差，逐步露出悬空长桥；3–5秒镜头继续小幅升高约2米并减速，完整显露云海后的白玉天门；5–6秒完全停稳。云海单向缓移，衣袖轻动。结束时人物在左下、天门占右上，路径清晰。禁止快速推进、无理由环绕、天门变形和全局金黄。
```

## 案例 2：高速追逐——静机位掠过 + 加速后跟

适用：竹林、屋脊、峡谷、御剑追击；展示速度而不靠全程抖动。

```text
5秒，16:9，35mm。低位静机位贴近湿润石阶，前0.8秒只见雨滴与摇动竹影；成年剑修从远处高速冲近并掠过镜头，追兵剑光随后进入。1秒处切换为同方向低位后跟，镜头由中速加速至快速，保持人物背影占画面高度25%，沿石阶直线追随；最后0.7秒人物跃出崖口，镜头急停在边缘，远处御剑轨迹继续前冲。运镜目的：用静/动反差制造爆发，再交代追逐方向。禁止随机摇晃、突然反向、人物复制、竹林融化。
```

## 案例 3：打斗冲击——等待 + 120°弧线 + 硬停

适用：一招定胜负、拔剑、法术对撞。

```text
4秒，21:9，50mm中景。两名成年剑修在白玉台两端对峙，镜头固定0.7秒制造等待；主角出剑时，镜头以中快速度沿主角外侧完成约120度短弧线跟随，保持对手始终在背景同一侧；剑光相撞瞬间加入一次低幅、2帧感的冲击震动，随后镜头立刻停稳0.8秒，显示对手剑尖断裂。运镜目的：围绕单一攻击建立方向与结果。禁止完整360度环绕、连续震动、多人复制、建筑滑动和一镜塞入多套招式。
```

## 案例 4：压迫对峙——锁定机位 + 长焦微移

适用：长老审判、师徒决裂、魔尊现身；证明“没有大运镜”也可以有力量。

```text
6秒，16:9，85mm长焦。低机位中远景，成年女剑修背对镜头站在大殿中央，九级台阶上的宗主位于画面正中。前2秒完全锁定，只有烛火与衣摆轻动；2–5秒镜头极缓向左移动不到0.8米，让前景立柱逐渐压缩女剑修的空间；5–6秒停稳，宗主抬眼。运镜目的：用长焦压缩和遮挡增加权力压迫，而非炫技。禁止推拉、环绕、摇晃、立柱变形和视线轴反转。
```

## 案例 5：认知反转——dolly zoom + 恢复稳定

适用：发现身份真相、幻境破裂、天门其实是封印。

```text
4.5秒，16:9，50mm起始。成年修士近景凝视门上纹章，前1秒镜头静止；1–3秒相机向后移动约4米，同时做受控光学变焦保持人物头部大小基本不变，使背景天门被视觉压近；3–4.5秒停止变焦，继续轻微后退并减速，人物转身看向镜头外的真实出口。运镜目的：用空间感异常表达认知冲击，随后恢复可读地理。禁止数字变焦脉冲、持续滚转、人物脸部漂移和天门几何变化。
```

## 案例 6：情绪告别——人物离开，镜头不追

适用：离别、牺牲、拒绝、余韵。

```text
7秒，4:5，65mm中远景。相机完全锁定在桥头，两名成年人物一前一后站立。前方人物停顿1秒后向云雾深处离开，后方人物保持原地；镜头不跟随，让离开者从中景缩小并被雾吞没。最后2秒空桥与留下的人共同停留。运镜目的：以拒绝追随制造不可挽回的距离。只允许雾单向移动和衣袖轻摆。禁止慢推、环绕、自动重新居中和人物瞬移。
```

## Sequence diversity check

For a multi-shot plan, inspect the actual verbs rather than labels:

- Are several shots all effectively moving toward the subject?
- Does each movement reveal new information or alter emotion?
- Does the speed curve match the action-energy curve?
- Is at least one still or settling moment available for readability?
- Are complex moves divided into ordered phases?
- Could the target model maintain character and architecture under this path?

If diversity exists only because “push”, “dolly in”, and “move forward” use different words, rewrite the sequence.
