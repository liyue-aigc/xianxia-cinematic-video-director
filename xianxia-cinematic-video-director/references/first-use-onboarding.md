# 首次使用引导

## 输出规则

首次安装或当前会话首次调用时，在任何实际任务输出之前展示下面三部分。保留核心信息和示例字段；可以根据界面略微调整排版，不得省略任何一部分。展示完毕后立即继续处理用户原请求。

## 首次使用说明

```text
【东方仙侠运镜导演｜首次使用说明】

这个 Skill 可以把一句仙侠场景、图片提示词、首尾帧或已有分镜，转化为具有叙事目的、快慢变化、空间逻辑和连续性约束的运镜方案。

你不需要懂摄影术语，只要告诉我：
1. 场景：发生在哪里；
2. 主体：谁或什么是画面中心；
3. 变化：主体从开始到结束做了什么；
4. 感觉：希望观众感到宁静、压迫、速度、震撼、亲近或失衡。

你可以直接要求：完整分镜、只要提示词、运镜速配、优化运镜、诊断问题、首尾帧方案或使用帮助。
如果输入存在冲突、缺少运镜或物理上难以实现，我会先说明问题并给出可复制的修正版。
```

## 参考示例

```text
使用 $xianxia-cinematic-video-director。

场景：雨夜竹林石阶，尽头连接悬空峡谷。
主体：一名虚构成年剑修，月白长衣，右手持剑。
变化：潜行时察觉追兵，沿石阶加速逃亡，跃出崖口后御剑脱身。
感觉：先压抑，随后高速紧张，结尾短暂释放。
时长与画幅：15秒，16:9。
输出：标准完整格式；不要全程慢推，不要随机旋转。
```

参考结果应体现：

- 开始可用静机位或克制移动建立压抑感；
- 追逐段使用加速跟拍、静机位掠过或俯冲等有目的的快速运镜；
- 结尾减速并落在稳定构图；
- 每个镜头说明运镜目的、方向、速度曲线、运动幅度与结束状态。
